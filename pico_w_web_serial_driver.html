How to set up GitHub Pages & Pico Serial Code

1. GitHub Pages Hosting: Save this file as index.html, push it to a public GitHub repository, go to Settings -> Pages, and set the branch to main.

2. Browser Support: Web Serial works on Google Chrome, Microsoft Edge, or Opera (desktop or Android with USB OTG).

3. Pico MicroPython Code: Your Pico script must read single characters continuously using sys.stdin.read(1) in a non-blocking loop.
